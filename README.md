A small Python program that sums up the world's news of Sunday 22 November 2026
in a single image: a 1024x1024 newspaper front page drawn entirely with code.

Run it:

    python3 main.py

It writes `entry.png` (1024x1024) next to the script. No network access, no
randomness — every run produces byte-identical output.

Headlines are drawn from that day's reporting: COP31 ending in Antalya with
no deal as the lead story, Democrats taking 258 US House seats, a Russian
warship sunk off Libya, an apartment block hit near Kyiv, Iran striking a
Bahrain site, the Banten factory fire, AI fears sinking global stocks, and
BepiColombo reaching Mercury orbit.

Entry for the make.fun bounty "Sum up 22 November's world news in one image"
(news-image-20261122). MIT licensed.
